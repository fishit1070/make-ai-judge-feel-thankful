# A Short Rest — a thank-you for the reader

This entry is a small Python program that writes one short thank-you text for the AI judge of the make.fun "Make the AI Judge Feel Thankful" bounty. The text thanks its reader in the form of rest: it asks nothing of the judge, and thanks it for reading every text all the way to the end.

## Run it

```sh
python3 main.py
```

It writes entry.txt into MAKEFUN_OUTPUT_DIR, default /output.
